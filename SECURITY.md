# Security policy

## Reporting a problem

Please [report security problems privately](https://github.com/CodeNKoffee/csen909-ilovetests/security/advisories/new). Do not open a public issue.
We aim to reply within a week.

## Scope

iLoveTests is a static prototype. It has no server, no accounts and no real pupil data; demo progress is kept in your own browser's local storage. Reports about the site's headers, scripts or dependencies are welcome.

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |
