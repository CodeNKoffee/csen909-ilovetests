# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, and keep feedback about the work.

## Reporting

If someone breaks these rules, contact the maintainer, [Hatem Soliman](https://hatemsoliman.dev), privately.
We will reply within a week and keep reports confidential.
