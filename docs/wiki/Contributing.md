# Contributing

The full guide is [CONTRIBUTING.md](https://github.com/CodeNKoffee/csen909-ilovetests/blob/main/CONTRIBUTING.md). In short:

| | |
|---|---|
| Report a bug | [New bug report](https://github.com/CodeNKoffee/csen909-ilovetests/issues/new?template=bug_report.md) |
| Suggest a feature | [New feature request](https://github.com/CodeNKoffee/csen909-ilovetests/issues/new?template=feature_request.md) |
| Security problem | [Report privately](https://github.com/CodeNKoffee/csen909-ilovetests/security/advisories/new) |
| What changed | [CHANGELOG.md](https://github.com/CodeNKoffee/csen909-ilovetests/blob/main/CHANGELOG.md) |

This wiki is edited through `docs/wiki/` in the main repository and published with `scripts/publish-wiki.sh`. Edits made on the website are overwritten.
