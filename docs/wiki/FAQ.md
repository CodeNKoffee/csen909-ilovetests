# FAQ

**Is the AI real?** No. Text reading, confidence, suggested marks, hints and flags are fixed data, as our course brief allows. See [[Your Data and Reset]].

**Can the AI release grades on its own?** No. Only the teacher confirms grades, decides red flags and releases results. See [[Assistant Role]].

**Why is page 2 always blurry?** The demo does it on purpose to show the blur check. See [[Student View]].

**Why are there no red crosses?** The app is for young children. We use "Not yet" and blue tones, and avoid red and green, which colour-blind users can't tell apart.

**I'm stuck halfway. How do I start again?** Use **Reset demo** in the guide. See [[Your Data and Reset]].

**Does it work on a phone?** Yes. The demo guide becomes a small button above the bottom menu. See [[Getting Started]].
