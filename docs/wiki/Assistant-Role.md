# Assistant role

At the bottom of the teacher side menu, **Signed in as** switches between **Mrs Rasha** and **Hatem**.

| Action | Hatem (assistant) | Mrs Rasha (teacher) |
|---|---|---|
| Check the text | Yes | Yes |
| Change marks and comments | Yes, saved as a draft | Yes |
| Confirm grades | No: **Send draft to Mrs Rasha** | **Confirm all grades** |
| Confirm or dismiss red flags | No | Yes |
| Release results | No | Yes |

Drafts show as *Draft by assistant* until the teacher confirms them.
